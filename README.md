Resolución del ejercicio N°38 de la unidad 2 de programación 2.
Este programa implementa un sistema modular para generar y renderizar distintos tipos de gráficos visuales a partir de un conjunto de datos numéricos, aplicando validaciones de integridad para asegurar que existan elementos antes de procesar la representación gráfica.

Clases utilizadas
GeneradorGrafico
GraficoBarras
GraficoCircular
GraficoLineal
